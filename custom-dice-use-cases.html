Quote checklist

What to send for this custom dice use case.

  • Buyer type and sales channel.
  • Catalog SKU list, comparable product photo, or custom concept description.
  • Target quantity or MOQ range for sample, first order, and reorder plan.
  • Material preference: resin, sharp edge resin, metal, hollow, liquid core, oversized D20, or mixed assortment.
  • Packaging requirement: bag, tin, box, display carton, insert card, barcode label, or private label packaging.
  • Delivery country, target launch date, and whether samples are needed before production approval.

FAQ

Common buyer questions.

Are these real customer case studies?

No. These are buyer scenarios that explain how different B2B buyers can plan custom or wholesale RPG dice projects without claiming a specific customer order.

Which page should a new buyer start with?

Start with the page that matches your sales channel. Game stores should start with the game store page; creators should start with the Kickstarter RPG campaign page; brands should start with the private label dice page.

What should I send for a faster quote?

Send target dice type, catalog SKUs or reference photos, quantity target, packaging format, delivery country, launch date, and any custom logo or symbol requirements.
